# Tara Ctara — E-Commerce Website

A recreated, improved version of the earlier **Tara Ctara** student e-commerce concept. This is a front-end demo built with HTML, CSS, and vanilla JavaScript. It is **not the recovered original source code**.

## Features
- Responsive storefront layout for desktop, tablet, and mobile
- Product category filtering
- Product search and price sorting
- Add-to-bag interactions with quantity controls and subtotal
- Cart and wishlist saved in browser `localStorage`
- Newsletter form feedback (demo only)
- Accessible labels and semantic sections
- No payment gateway or backend; checkout is a demo interaction

## Run locally
1. Download and extract the project folder.
2. Open `index.html` in a browser.
3. For a better local development experience, use VS Code with the Live Server extension.

No package installation is required.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — products, filters, wishlist, and cart logic
